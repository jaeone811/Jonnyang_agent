# 존냥이 (Jonnyang) =^.^=

Windows 10/11용 규칙 기반 한국어 개인 비서. 고양이 캐릭터. LLM/AI API 없이 키워드·형태소·유사도 규칙으로만 명령을 알아듣는다.

바탕화면 구석에 떠 있는 데스크톱 펫이다. 하얀 장모 고양이에 금색 왕관과 남색 망토를 두른 존냥이가 말풍선에 지금 하는 일(타이머 남은 시간, 다음 알람, 날씨 알아보는 중, 대답 기다리는 중)을 보여주고, 고양이 밑 입력창에 말을 걸면 된다. 사용자 컨셉 아트·스프라이트 시트에서 잘라낸 그림을 쓴다. 그림은 가만히 두고 숨쉬기·깡총·갸웃 같은 작은 움직임과 반짝이·하트·물음표 효과만 코드로 더한다. 클릭하면 몸이 통통 튀며 하트가 뜨고, 일할 때는 노트북·마법책·폴더 그림으로, 끌고 다니면 둥실 떠 있는 그림으로 바뀐다.

## 다운로드해서 바로 실행 (Python 설치 필요 없음)

1. GitHub 저장소의 **Releases**에서 `Jonnyang-버전-win64.zip`을 받는다.
   - 아직 릴리스가 없으면 **Actions** 탭 → 최신 "Windows test & build" 실행 → 아래 **Artifacts**의 `Jonnyang-…-win64`를 받는다 (GitHub 로그인 필요, 30일 보관).
2. 압축을 풀고 `Jonnyang\Jonnyang.exe`를 더블클릭. `_internal` 폴더는 exe 옆에 그대로 둬야 한다.
3. "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행] (코드 서명을 안 해서 뜨는 경고).

### 다운로드나 실행이 "위험"하다고 막힐 때
코드 서명(유료 인증서)을 안 한 exe라서, 처음 보는 파일을 막는 브라우저·백신 평판 검사에 걸린다. 받은 파일이 이 저장소 Actions/Releases에서 온 게 맞을 때만 아래처럼 푼다.
- **Edge**: 다운로드 목록(Ctrl+J)에서 막힌 파일 → […] → [유지] → 다음 창에서 [삭제] 옆 화살표(∨) → [그래도 계속].
- **Chrome**: `chrome://downloads` → 막힌 파일 옆 메뉴 → [위험한 파일 다운로드] → 경고 화면에서 계속.
- **"바이러스가 검색됨"/Windows 보안이 지움**(Trojan:Win32/Wacatac…!ml 같은 이름): PyInstaller exe에 흔한 오탐이다. 이 경우 브라우저에서는 풀 수 없다. 대신 아래 둘 중 하나를 한다.
  - Windows 보안 → 바이러스 및 위협 방지 → 보호 기록에서 해당 항목 → [작업] → [장치에서 허용] (격리됐으면 [복원]). 이미 지워졌으면 허용한 뒤 다시 받는다.
  - exe 없이 아래 "소스로 설치"대로 Python으로 실행 (같은 프로그램)

- 설정: exe 옆 `config\*.yaml`을 메모장으로 고치고 다시 켜면 된다.
- 내 데이터(목록·리마인더·별칭·설정): `%LOCALAPPDATA%\Jonnyang\jonnyang.db`. 새 버전은 `Jonnyang` 폴더만 갈아끼우면 데이터가 남는다.
- 오류가 나면 `%LOCALAPPDATA%\Jonnyang\crash.log`에 내용이 남고 대화상자로도 뜬다.
- 크기가 큰 편이다: 형태소 분석 모델만 약 105MB.

새 릴리스 만들기(개발자용): `git tag v0.2.0 && git push origin v0.2.0` → Windows 러너가 테스트·빌드·exe 자체 점검 후 Release에 zip을 올린다 (`.github/workflows/windows.yml`).

## 소스로 설치 (Windows, 개발용)

1. **64비트 Python 3.12 또는 3.13** 설치 (pycaw는 3.10 이상 필요, kiwipiepy Windows 휠은 x86-64용만 있음).
   - `python`을 치면 Microsoft Store가 뜨면: 설정 → 앱 → 앱 실행 별칭에서 python 끄거나 `py -3.12` 사용.
2. **프로젝트 폴더(`pyproject.toml`이 있는 곳)에서** 가상환경 만들고 설치:
   ```powershell
   cd C:\경로\Jonnyang_agent
   py -3.12 -m venv .venv
   Test-Path .\.venv\Scripts\python.exe    # True가 나와야 다음 단계로
   .\.venv\Scripts\python.exe -m pip install -e ".[dev]"
   ```
   - kiwipiepy 모델(약 105MB)이 같이 받아진다. 느려도 정상이다.
   - 활성화(`Activate.ps1`) 없이 `.\.venv\Scripts\python.exe`를 직접 쓰면 실행 정책 문제도 피한다.
3. 실행:
   ```powershell
   .\.venv\Scripts\jonnyang-pet.exe              # 데스크톱 펫 (콘솔 창 없이)
   .\.venv\Scripts\python.exe -m jonnyang         # 같은 펫, 오류가 콘솔에 보임 (문제 생기면 이걸로)
   .\.venv\Scripts\python.exe -m jonnyang --cli   # 예전 콘솔 채팅
   ```
   - 바로가기를 만들려면 `jonnyang-pet.exe`를 우클릭 → 바로 가기 만들기. 시작프로그램 폴더(`Win+R` → `shell:startup`)에 넣으면 부팅 때 같이 뜬다.
   - 콘솔 모드에서 이모지가 네모로 나오면 Windows Terminal을 쓰거나 "이모지 꺼"라고 말하면 된다. 콘솔 디버그: `/nlu 문장`, `/time 문장`.

### 펫 다루기

| 동작 | 결과 |
|---|---|
| 입력창에 쓰고 Enter | 명령 실행. ↑/↓로 이전 입력 |
| 고양이 끌기 | 위치 이동 (다음 실행 때 기억) |
| 고양이 클릭 | 쓰다듬기. 알림 말풍선이 떠 있으면 확인 처리 |
| 고양이 더블클릭 | 입력창 숨기기 / 보이기 |
| 고양이 우클릭 | 메뉴: 입력창, 도움말, 냥체·이모지 켜고 끄기, 숨기기, 종료 |
| 트레이 아이콘 클릭 | 숨긴 존냥이 다시 보이기 |
| 말풍선의 응/아니·번호 버튼 | 확인·되묻기에 바로 대답 |

- 말풍선 상태(Codex 펫처럼): 🔵 작업 중 / 🟠 대답 기다리는 중 / 🟢 완료 / 🔴 문제 생김 / 🟧 알림.
- 응답은 몇 초 뒤 사라지고 진행 중인 일이 있으면 그걸 보여준다. 할 일이 없으면 말풍선이 숨고, 고양이에 마우스를 올리면 다시 뜬다.
- 확인 질문과 알림(타이머 끝 등)은 대답하거나 클릭할 때까지 남는다. 알림이 연달아 오면 덮어쓰지 않고 이어 붙이고, 확인 질문 중에 알림이 오면 알림을 본 뒤 질문으로 돌아온다.
- 응답을 보여주는 시간은 글 길이에 맞춘다(4~25초). 말풍선에 마우스를 올려 두면 안 사라진다.
- 날씨·뉴스처럼 인터넷이 필요한 건 고양이가 노트북을 두드리며 기다리고, 그동안에도 펫은 멈추지 않는다.
- 창을 숨겨둔 상태일 때만 트레이 알림이 뜬다(보이는 상태에선 말풍선과 겹치지 않게).
- 10분 동안 아무것도 안 하면 존다(zZ). 클릭하거나 말을 걸면 깬다.
- 한 번에 하나만 실행된다(리마인더가 두 번 울리지 않게). 이미 떠 있으면 안내만 뜬다.

### 설치가 안 될 때

| 증상 | 원인 / 해결 |
|---|---|
| `'.venv' 모듈을 로드할 수 없습니다` (CouldNotAutoLoadModule) | `.venv\Scripts\python.exe` 파일이 없어서 PowerShell이 `.venv`를 모듈 이름으로 읽은 것. 가상환경이 안 만들어졌거나 다른 폴더에 있다. `Test-Path .\.venv\Scripts\python.exe`로 확인하고, False면 2단계 `py -3.12 -m venv .venv`부터 다시. |
| `py`를 찾을 수 없음 | python.org 설치 프로그램으로 다시 설치하면서 "py launcher" 체크. 또는 `python -m venv .venv` (단 `python --version`이 3.10 이상 64비트여야 함). |
| `No suitable Python runtime found` | `py --list`로 설치된 버전 확인. 3.12가 없으면 있는 버전(3.10 이상)으로 `py -3.13 -m venv .venv`처럼 바꾼다. |
| `python`이 Microsoft Store를 염 | 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 python 끄기. |

WSL에서는 볼륨 조절(pycaw)이 안 된다. 개발은 아무 OS에서 해도 되고, 테스트는 가짜 OS 어댑터로 돈다.

### 온라인 (인터넷이 끊기면 그 기능만 "지금은 못 한다"고 안내)

| 분류 | 예시 | 출처 |

| 날씨 | "오늘 날씨 어때", "내일 부산 비 와?", "이번 주 날씨", "우리 동네 대전으로 설정해" | [Open-Meteo](https://open-meteo.com) (API 키 없음) |
| 미세먼지 | "미세먼지 어때", "강릉 공기 어때" — 환경부 예보 등급(좋음/보통/나쁨/매우나쁨)으로 표시 | Open-Meteo 대기질 (CAMS 모델 추정치, 측정소 실측 아님) |
| 환율 | "달러 환율", "엔화 환율"(100엔 기준), "100달러는 몇 원이야", "5만원은 몇 달러야" | [Frankfurter](https://frankfurter.dev) v2 (중앙은행 기준 환율, 하루 1회 갱신) |
| 위키백과 | "광합성이 뭐야", "아인슈타인이 누구야", "위키에서 고양이 찾아줘" | 한국어 위키백과 |
| 뉴스 | "뉴스 보여줘", "IT 뉴스", "축구 뉴스", "'인공지능' 뉴스" → "2번 기사 열어" | Google 뉴스 RSS (`config/online.yaml`에서 바꿈) |

- 가져온 글(위키 요약, 기사 제목)은 보여주기만 한다. 그 안에 "타이머 맞춰" 같은 말이 있어도 명령으로 처리하지 않는다.
- 파일 작업은 `aliases.yaml`의 폴더(바탕화면·다운로드·문서 등) 안에서만 한다. 지우기는 휴지통으로만 보내고(영구삭제 없음), 휴지통·옮기기·정리는 대상 목록을 보여주고 확인받는다. 옮기기·정리·이름 바꾸기는 "되돌려"로 원래대로 돌린다. 같은 이름이 있으면 덮어쓰지 않고 " (2)"를 붙인다.
- 반복 알림: 매일 / 평일 / 주말 / 매주 ○요일 / ○분·○시간마다. "매달", "격주"는 아직 안 된다.

- 부정문은 실행 안 함: "볼륨 올리지 마", "알람 안 맞춰도 돼"
- "X 말고 Y"는 Y를 실행: "타이머 말고 내일 7시 알람", "끄지 말고 소리 줄여줘"
- 지우기·비우기·덮어쓰기·되돌리기는 대상 목록을 보여주고 "응/아니"로 확인받는다.
- 점수가 애매하면 실행하지 않고 되묻는다("타이머" → "1. 타이머 맞추기 2. 남은 시간 보기").

## 고치고 싶을 때

| 파일 | 내용 |
|---|---|
| `config/persona.yaml` | 모든 대사. 프로필(soft 순한 냥체 / chic 시크 / dc 디시 / plain 냥체 끔), 고양이·말풍선 색(`appearance`), 응답별 표정(`poses`), 펫 문구(`ui`) |
| `config/aliases.yaml` | 앱·폴더 별칭 (실행 파일, 전체 경로, `ms-settings:` 같은 URI) |
| `config/lexicon.yaml` | 동의어 묶음(켜/틀/실행 → OPEN 등), 형태소 분석기 사용자 단어 |
| `config/settings.yaml` | 호출어 필수 여부, 매칭 임계값, 확인 대기 시간, 리마인더 기본 시각 |
| `config/online.yaml` | 온라인 기능 켜고 끄기, 서버 주소, 기본 지역, 지역 좌표, 날씨 코드 이름, 미세먼지 등급, 통화 이름, 뉴스 피드 |
| `config/files.yaml` | 파일 찾기 범위(깊이·개수), 정리할 때 만드는 폴더와 확장자, "사진"·"엑셀" 같은 말 → 확장자 |

프로그램은 `config/`를 읽기만 한다. 명령으로 바꾼 설정·별칭·목록·리마인더는 `data/jonnyang.db`(SQLite)에 저장된다.

## 한계

- 리마인더·알람은 프로그램이 켜져 있을 때만 울린다. 꺼져 있던 동안 지난 것은 다음 실행 때 "놓친 알림"으로 알려준다(반복 알림은 한 번만 알리고 다음 회차로 넘어간다).
- "매달"·"격주" 반복, 시간 범위("3시부터 5시"), 공휴일·음력, "이따가" 같은 모호한 시간은 안 된다(안내 메시지만 냄).
- 붙여 쓴 한 글자 한자어 수사는 숫자로 안 바꾼다: "오 분"은 되고 "오분"은 안 된다("구분", "엔진 오일" 오인 방지).
- 미세먼지는 대기 모델 추정치라 에어코리아 측정값과 다를 수 있다.
- 파일 휴지통 보내기는 되돌리기로 복원하지 않는다(Windows 휴지통에서 직접 복원).
- 펫을 부르는 전역 단축키는 아직 없다(입력창을 클릭해야 한다).
