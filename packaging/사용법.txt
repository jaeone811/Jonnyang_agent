존냥이 (Jonnyang) 데스크톱 펫
================================

실행
  Jonnyang.exe 를 더블클릭. 화면 오른쪽 아래에 고양이가 뜬다 (처음엔 몇 초 동안 졸면서 깨어난다).
  _internal 폴더는 지우거나 옮기면 안 된다. 폴더 통째로 원하는 곳에 두면 된다.

"Windows의 PC 보호" 파란 창이 뜨면
  코드 서명을 안 한 프로그램이라 그렇다. [추가 정보] → [실행] 을 누르면 된다.

부팅할 때 같이 켜기
  Jonnyang.exe 우클릭 → 바로 가기 만들기 → Win+R 에 shell:startup 입력 → 열린 폴더에 바로 가기 넣기.

다루기
  입력창에 말하고 Enter          명령 실행 (예: 3분 타이머, 쇼핑 목록에 우유 추가해, 뭐 할 수 있어?)
  고양이 끌기                    위치 이동
  고양이 클릭                    쓰다듬기 / 알림 확인
  고양이 더블클릭                입력창 숨기기·보이기
  고양이 우클릭                  메뉴 (도움말, 냥체·이모지, 숨기기, 종료)
  트레이 아이콘 클릭             숨긴 고양이 다시 보이기

설정 고치기
  config 폴더의 yaml 파일을 메모장으로 고치고 존냥이를 다시 켜면 된다.
    persona.yaml   대사, 말투, 고양이 색, 표정
    aliases.yaml   "메모장 켜줘" 같은 앱·폴더 별칭
    settings.yaml  호출어, 매칭 기준 등

내 데이터 (목록, 리마인더, 등록한 별칭, 설정)
  %LOCALAPPDATA%\Jonnyang\jonnyang.db
  새 버전으로 바꿀 때는 Jonnyang 폴더만 통째로 갈아끼우면 데이터는 그대로 남는다.

문제가 생기면
  %LOCALAPPDATA%\Jonnyang\crash.log 에 오류 내용이 남는다. 그 내용을 알려주면 된다.
